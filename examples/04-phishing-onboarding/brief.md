# Brief: Phishing awareness onboarding

**Input style:** raw, messy notes pasted as-is. The skill turns them into a deck.

- **Type:** 15-minute onboarding session for new hires at "Harbourline Logistics", a fictional company
- **Slides:** 5

The security team's notes:

```
phishing session for new starters - 15 min, keep it practical not scary
- most attacks start w/ an email or chat msg that looks totally normal (invoice, parcel, HR doc, "shared file")
- red flags: urgent / "act now", sender address slightly off (harbourl1ne...), link text != where it goes (hover!), asks for password or MFA code, unexpected attachment esp. zip/htm
- what to do: dont click, dont reply, use the Report button in the mail app -> goes to security team
- clicked already?? -> tell IT helpdesk straight away, ext 4400, NO blame, faster = better
- MFA fatigue - if you get push prompts you didnt start, tap Deny + report. never approve just to make it stop
- IT will NEVER ask for your password or MFA code. ever.
- maybe end with a quick "spot the fake" example email?? (make it obviously fictional)
- tone: friendly, we're on the same team
```
